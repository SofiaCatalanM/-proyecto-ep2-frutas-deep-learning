# Clasificador de Frutas con Deep Learning

## Integrantes
- Sofía Catalán
- Bastián Román

## Descripción
Sistema de clasificación de 9 tipos de frutas usando MobileNetV2 con Fine-Tuning,
API REST y aplicación móvil.


## ejecutar aplicacion
1.-primero se debe ejecutar la api con el comando:
python api.py en la terminal

2.-Segundo lugar se debe ejecutar la aplicacion con el comando:
python app_movil.py en una terminal aparte
